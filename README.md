# 失控的完美答案｜AI 幻覺與偏見密室

給國中以上學生的單頁媒體識讀闖關遊戲。學生以 FACT 四步驟完成四個貼近日常的任務：班級群組裡的可疑研究、帶有角色偏見的 AI 校園配圖、需要核對的校園規定，以及刻板印象文案的修正。

## 教學重點

- **F - Find 找出可疑**：辨識無來源、過度精確、太絕對或疑似虛構的資訊。
- **A - Ask 追問依據**：追問根據、資料來源、缺少的觀點與誰沒有被呈現。
- **C - Check 查證比對**：核對發布者、日期、原文、適用範圍與多個獨立來源。
- **T - Transform 修正轉化**：把錯誤、單一或偏誤內容改成正確、多元、尊重差異的表達。

每一關都有提示、錯誤原因、正確判斷規則與破關後的課堂延伸問題，不以分數取代學習回饋。
